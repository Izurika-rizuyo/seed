# Changelog

## 0.2.6 — 13.11.2026

**Второе устройство через репозиторий**
- В «Добавить проект → Из репозитория» можно выбрать репозиторий, через который синхронизируется проект: Seed подключит это устройство к проекту, а не откроет зашифрованные файлы. Ссылка-приглашение не нужна.
- На первом устройстве в «Настройки → Синхронизация» появится запрос с кодом — сверьте его и подтвердите.
- Если в выбранном для синхронизации репозитории уже есть другой проект, Seed предупредит об этом.

**Синхронизация**
- Плагины, созданные на вашем устройстве, приходят на другие устройства включёнными.
- Синхронизируются включённые пакеты, методы и боковая панель.

**Важно**
- Обновите оба устройства: запрос по репозиторию понимает только 0.2.6.

## 0.2.5 — 13.11.2026

**Плагины без лимита размера**
- Лимит 64 КБ на плагин снят. Код плагинов хранится отдельно от списка плагинов, каждый файл один раз: история версий и синхронизация переносят только изменённое.
- У плагина могут быть свои файлы — JS, CSS, JSON, SVG, Markdown — рядом с `plugin.json` в папке `plugins/<id>/`. Страница подключает их обычными относительными ссылками, данные читаются через `hub.plugin.files.read`.
- Отказ — только при аварийных размерах (файл больше 5 МБ, плагин больше 100 МБ); для файла больше 200 КБ Seed советует разбить его на модули.
- Включение и выключение плагина больше не пересылает его код.

**Важно**
- Обновите все устройства проекта вместе: Seed 0.2.4 и старше не читает новое хранение плагинов.

## 0.2.4 — 13.11.2026

**Файлы проекта**
- Слова token, password, secret в имени больше не закрывают вёрстку и медиа: `tokens.css`, `password-reset.html`, картинки, шрифты читаются и копируются.
- Открыты папка `vendor/`, обычные служебные файлы (`.gitignore`, `.vercelignore`) и папки `.github`, `.storybook`, `.vscode`. `.env`, `.npmrc` и ключи по-прежнему закрыты.
- Если файл закрыт, ошибка называет его и причину.

**Плагины**
- Путь `hub/…` в плагине ведёт в рабочую папку проекта (например `seed/`); отсутствующий файл — понятное «не найдено» вместо сбоя.
- Плагины читают текстовые файлы проекта: `.json`, `.html`, `.js`, `.css`, `.svg`, `.yaml`.
- Клик во встроенном сайте внутри плагина позволяет сразу открыть документ, без второго клика.
- Размер плагина виден в его описании; при превышении 64 КБ ошибка показывает размер и самые большие части.

**Агент**
- Большая карта сайта читается оглавлением, полные страницы — по выбору; ответы о рабочей папке и плагинах стали короче.

## 0.2.3 — 13.11.2026

**Синхронизация через GitHub**
- Подключение как у моделей: кнопка «Войти через GitHub» открывает github.com в браузере, Seed показывает одноразовый код и сам замечает подтверждение. Терминал и ручной ввод адреса больше не нужны.
- После входа: «Новый репозиторий» — Seed создаёт приватный репозиторий и сразу включает синхронизацию, или «Существующий» — выбор из ваших приватных репозиториев с поиском.
- Тот же вход — на экране «Добавить проект».
- Токен хранит GitHub CLI; Seed его не видит.

## 0.2.2 — 12.11.2026

**Обновления**
- Кнопка «Проверить обновления» в «Настройки → Платформа → Обновления» и проверка раз в день (можно выключить).
- Обновление скачивается только по кнопке и ставится после проверки подписи, размера и SHA-256; вернуться на прошлую версию можно в один клик.
- Если новой версии нужен другой Electron, Seed предлагает скачать установщик.

**Плагины**
- Новый менеджер плагинов: вкладки «Каталог», «В проекте», «Библиотека», поиск и одна кнопка на карточке.
- Пакет **Design Workflow v0.1**: Бриф, Решения, Карта сайта и Документы. Встроен в приложение, включается без загрузки, части можно переключать по одной.
- Плагины из официального репозитория скачиваются, сверяются с подписанным каталогом и сразу подключаются к проекту.
- Свой плагин можно предложить через pull request (см. CONTRIBUTING.md); в каталог он попадает после проверки и переподписи.
- Плагины проекта больше не теряются: изменённая в проекте копия не заменяется новой версией без вашего выбора, прошлая версия остаётся в истории.

**Установка**
- macOS (Apple Silicon): `Seed-0.2.2-mac-arm64.dmg`; Windows x64: `Seed-Setup-0.2.2-win-x64.exe`.
- С 0.2.1 — файл `.seedupdate` своей системы через «Установить из файла»; дальше обновления приходят по кнопке.

## 0.2.1 — 12.11.2026

- Новый логотип Seed.
- Экран «Добавить проект»: проекты, способы добавления и подключения в одной панели; клонирование из GitHub и автоматическая настройка git / GitHub CLI.
- Совместимость с Windows: запуск агентов, вход, Корзина, Tailscale, установка обновлений.
- «Настройки → Диагностика»: сведения об устройстве и отчёты о проблемах в проекте, общие для Mac и Windows.
